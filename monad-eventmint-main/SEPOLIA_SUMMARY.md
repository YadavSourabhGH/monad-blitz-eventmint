## ❓ Common Questions

**Q: Can I use Hardhat and Sepolia together?**
A: Yes! Deploy to both. They're independent.

**Q: Do I need real ETH for Sepolia?**
A: No! Testnet ETH is free from faucets.

**Q: Will my Hardhat data transfer to Sepolia?**
A: No, they're separate networks. Re-deploy.

**Q: Can I see Sepolia transactions?**
A: Yes! On Etherscan at https://sepolia.etherscan.io

**Q: What if I mess up on Sepolia?**
A: It's just testnet! Start over, no cost.

**Q: How long does Sepolia deployment take?**
A: Setup: ~20 minutes (one time)
   Deploy: ~5 minutes
   Transactions: ~30 seconds each

**Q: Is my private key safe?**
A: Yes, stored locally in .secret.json
   ⚠️ Never commit to git (already in .gitignore)
   ⚠️ Never share

**Q: Can I use the same code for mainnet?**
A: Yes! Just change network in hardhat config.
