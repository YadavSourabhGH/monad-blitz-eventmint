# ⚡ Monad Quick Start (15 min)

## 🎯 TL;DR

```bash
# 1. Get tokens
Open: https://faucet.monad.xyz/
Connect wallet → Claim tokens

# 2. Deploy
npx hardhat ignition deploy ignition/modules/EventChain.js --network monad

# 3. Update UI
Edit ui/src/web3Service.js with contract addresses

# 4. Run
cd ui && npm start

# 5. Test
Open http://localhost:3000
Connect wallet to Monad network
Create event → Mint ticket → Validate!
```
